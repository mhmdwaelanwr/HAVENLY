# HAVENLY — Reviewer Overview

## Project Concept

HAVENLY is a real-estate discovery and property-management platform that connects property seekers with owners or agents who want to publish and manage listings.

The project is designed to solve two connected problems:

1. Property seekers need a faster and more organized way to discover, filter, review, save, and compare suitable properties.
2. Property owners and agents need a simple way to publish, update, and manage property listings.

---

## Primary Users

### Property Seeker

A user looking for a property to buy or rent.

Typical actions:

- Browse available listings.
- Search by location or keywords.
- Filter by price, property type, purpose, bedrooms, bathrooms, and area.
- Open a property details page.
- Save selected properties.
- Compare shortlisted options.
- Contact the property owner or agent.

### Property Owner / Agent

A user who wants to advertise and manage one or more properties.

Typical actions:

- Add a new property listing.
- Provide property details and images.
- Review published listings.
- Edit listing information.
- Remove unavailable listings.
- Manage listings from a dashboard.

---

## Main User Flow

### Property Seeker

**Discover → Search → Filter → Open Details → Save / Compare → Contact**

### Property Owner / Agent

**Add Property → Publish → Manage → Edit / Remove**

## Data Strategy

The first version of HAVENLY works with its own project dataset and user-added listings.

It does not require scraping or searching external real-estate websites. This keeps the project controlled, testable, and suitable for the final-project scope.

A future version may connect to approved third-party property services when official integrations are available.
